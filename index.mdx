## The ideas in one paragraph

A **flow** is a trigger plus an ordered run of steps. Steps transform data, branch on conditions, call external systems, and do native logistics work: ingest an order, rate shop, purchase a label, create a claim, send an EDI document. Runs execute durably: automatic retries, waits for external events, full replay, and an exception queue when something needs a human. Everything an integration platform usually bolts on, metering, audit, money safety, multi-tenant isolation, is built into the runtime.
